# Mentor's Seminar — задания на Go

Практические задачи по базовым конструкциям Go: условия, циклы, функции и арифметика.

Запуск из корня репозитория: `go run ./task01` и так далее по папке задания. В любой программе `q` завершает ввод.

## Задания

| Папка | Задание |
| --- | --- |
| `task01` | Калькулятор с проверкой |
| `task02` | Анализ числа |
| `task03` | Сумма и среднее от 1 до N |
| `task04` | Таблица умножения через функцию |
| `task05` | Максимум и минимум из N чисел |
| `task06` | Количество положительных, отрицательных чисел и нулей |
| `task07` | Сумма чётных чисел от 1 до N, делящихся на 3 |
| `task08` | Проверка простого числа |
| `task09` | Мини-банкомат |
| `task10` | Статистика последовательности |

### task01. Калькулятор

```text
Первое число: 10
Операция (+, -, *, /): /
Второе число: 4
Результат: 2.5
```

Сверх условия: деление на ноль не выполняется, неизвестная операция отклоняется, дробь можно ввести и с запятой.

### task02. Анализ числа

```text
Введите число N: 15
Число положительное.
Число нечётное.
Число делится и на 3, и на 5.
```

Сверх условия: ноль описан отдельно — он ни положительный, ни отрицательный, но чётный и делится на 3 и на 5.

### task03. Сумма и среднее

```text
Введите число N: 4
Сумма чисел от 1 до 4: 10
Среднее значение: 2.5
```

Сверх условия: сумма копится в `float64`, при `N < 1` программа просит ввести число ещё раз.

### task04. Таблица умножения

```text
Введите число: 6
Таблица умножения для 6:
6 x 1 = 6
6 x 10 = 60
```

Сверх условия: таблицу печатает функция `printTable`, после неё можно запросить таблицу другого числа.

### task05. Максимум и минимум

```text
Введите количество чисел N: 4
Число 1: 3
Число 2: -1
Число 3: 8
Число 4: 8
Максимальное значение: 8
Минимальное значение: -1
```

Сверх условия: принимаются дробные числа с точкой и с запятой, `N` меньше 1 отклоняется.

### task06. Положительные, отрицательные и нули

```text
Введите количество чисел N: 5
Число 1: 3
Число 2: -1
Число 3: 0
Число 4: 2,5
Число 5: -4
Положительных: 2
Отрицательных: 2
Нулей: 1
```

Сверх условия: ноль учитывается отдельным счётчиком, а не попадает в положительные или отрицательные.

### task07. Сумма подходящих чисел

```text
Введите число N: 20
Сумма подходящих чисел от 1 до 20: 36
```

Сверх условия: в сумму попадают только числа, которые одновременно чётные и делятся на 3 (`6 + 12 + 18`). Если таких чисел нет, сумма равна 0.

### task08. Простое число

```text
Введите число: 17
17 — простое число.

Введите число: 15
15 — не простое число: делится на 3.
```

Сверх условия: для составного числа программа называет найденный делитель. Числа меньше 2 объясняются отдельно: они не простые.

### task09. Мини-банкомат

```text
Введите начальный баланс: 1000
Выберите действие: 3
Сумма снятия: 1500
Ошибка: недостаточно средств

Выберите действие: 2
Сумма пополнения: 200
Баланс: 1200.00 руб.
История операций:
1. Пополнение на 200.00 руб., баланс: 1200.00 руб.
```

Сверх условия: неудачное снятие не меняет баланс и не попадает в историю. Суммы округляются до копеек, начальный баланс не может быть отрицательным.

### task10. Статистика последовательности

```text
Введите количество чисел N: 5
Число 1: 4
Число 2: -3
Число 3: 0
Число 4: 7
Число 5: 2
Сумма: 10
Среднее значение: 2
Максимальное значение: 7
Минимальное значение: -3
Чётных: 3
Нечётных: 2
```

Сверх условия: ноль считается чётным, отрицательные числа тоже проверяются на чётность. Все шесть показателей считаются за один проход.
